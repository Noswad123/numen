# Original 1x Metadata

The owner authorized removal of the four superseded original `spritesheet.png`
bitmaps after the approved contour HD assets were fully validated. The original
manifests and per-character import READMEs are retained byte-for-byte as historical
metadata; references in those import READMEs describe the original import, not a
promise that the bitmap remains bundled here.

Exact removed paths and original SHA256 values are recorded in
`../hd-promotion/original-removal.json` and the unchanged historical
`../hd-promotion/report.json`. Missing PNGs without that authorization are errors.
Restore matching owner-supplied originals from the external generation archives
in a separate regeneration checkout to reproduce the neural generation. Never
treat the active HD derivatives as 1x source inputs.
