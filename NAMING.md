# Numen: naming decision

**Status:** **Numen** selected by the project owner. Project folder: `~/Projects/numen`. Intended CLI spelling: `numen`.

## Criteria

- Fits the Jamal Arcana family alongside Djinn and other mystical tools.
- Connects naturally to technology, a companion, or an unseen animating presence.
- Short, pronounceable, and comfortable as a CLI command.
- Independent of any particular character design or source application.
- Does not reuse an existing ecosystem tool name.

## Selected name: Numen

**Numen** is Latin for divine power or presence. For this app, it evokes an unseen, animating presence within the machine: a familiar that makes the activity of running tools visible.

The name is compact, independent of Djinn, and does not tie the product to a particular character or rendering surface. Its technology connection is metaphorical rather than an established computing definition.

Possible positioning: **“A little spirit for your running processes.”**

The name is selected, but external availability and local command collisions still need checking.

## Earlier recommendation: Sprite

**Sprite** has a direct double meaning: a supernatural spirit and a graphical object used in computer graphics, often for animated characters. It captures both the arcana theme and the visible technical product without being tied to Djinn.

Its main weakness is distinctiveness: the word is widely used in graphics, games, and commercial branding. It was considered but not selected.

## Candidates considered

| Name | Mystical / technical connection | Tradeoff |
| --- | --- | --- |
| **Sprite** | Spirit + computer-graphics object | Strongest dual meaning; crowded name |
| **Familiar** | A spirit companion attending a magical practitioner | Best product-role match; weaker technical meaning |
| **Daemon** | Divine/intermediary spirit + background service | Best architectural match; very generic systems term |
| **Eidolon** | Image, phantom, or apparition; visible embodiment of hidden activity | Atmospheric; spelling/pronunciation friction |
| **Sigil** | Magical sign + programming symbol marking a variable's role/type | Strong dual meaning; sounds more like a symbol than a companion |
| **Numen** | Divine power or presence; suggests an animating presence in the machine | Compact and evocative; technical connection is metaphorical |

## Excluded: Wisp

Wisp fits the atmosphere, but `~/Projects/wisp` already exists as an Arcana tool for floating utility surfaces. Keep its name and responsibility distinct. It may be a future surface integration rather than a competing app name.

## Tradeoffs retained for reference

- Choose **Sprite** for the clearest mystical + technology pairing.
- Choose **Familiar** if the companion relationship matters most.
- Choose **Daemon** if the background-service identity matters most.
- Choose **Eidolon** for a more enigmatic, manifestation-oriented identity.

No external package registry, trademark, domain, or repository availability checks have been performed. Local command collisions for `numen` also need checking before implementation or distribution.
